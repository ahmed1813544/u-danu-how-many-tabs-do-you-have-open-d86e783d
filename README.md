## The entry

`main.py` (stdlib-only Python, no third-party imports) writes a single
number — digits only, nothing else — to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`): the honest count of open browser tabs.

The number is **137**: a working browser left open across several days of
research — documentation pages, half-read articles, reference tabs and a
few things kept open "to read later" that never got closed. It is high
enough to surprise, specific enough to read as a real counted total rather
than a round guess, and ordinary enough that a real person could genuinely
have it open right now.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # 137
```
